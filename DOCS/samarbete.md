# Repository samarbeten
Ett gemensamt repository gör det väldigt smidigt för ett utvecklingsteam att jobba i samma projekt samtidigt. Alla i teamet slipper bry sig om att av misstag skriva över varandras filer eller krocka i koden, eftersom allt sparas tryggt på ett ställe. Bilden som du (Benjamin) ritade på tavlan är ett perfext exempel på det.

När alla jobbar i sina egna grenar, så kallade branches, kan man bygga sina funktioner i fred innan allt slås ihop. Det gör det också lätt att kolla igenom varandras koder, samt hjälpas åt att fixa buggar och se till att allt håller bra kvaliet.

Hade det varit så att något kraschat så är det ingen fara alls, för man kan alltid gå tillbaka till en äldre version som fungerade.
