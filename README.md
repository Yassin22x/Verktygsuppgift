# Verktygsuppgift
I den här övningen testar jag att jobba me de olika verktygen en utvecklare jämt använder. Målet är att komma igång med terminalen för att styra filsystemet, skriva och dokumentera i VS Code, samt att lära mig grunderna i Git och Github för att senare spara och ladda upp koden. Avslutningsvis så kommer jag att dubbellkolla instruktionerna som getts ut för att säkra mig på att jag gjort rätt.

## Mina git kommandon
- git init - Använde jag för att starta och skapa mitt Git-repository i min projektmapp.
- git add - Jag använde detta för att förbereda README.md inför min första commit.
- git commit - Den använde jag för att spara min första version i historiken med meddelandet "uppdaterar README".
- git branch - Jag använde detta med -M main för att säkerställa att min huvudgren hette main.
- git remote - Jag använde "git remote add origin" för att koppla ihop min lokala mapp med mitt repository på GitHub.
- git push - Jag använde det med -u origin main för att skicka upp min första commit till GitHub.

## Begrepp inom git
- Repository - Det är en mapp och ett projekt där filerna och projektens hela historik sparas/spåras.
- Commit - Det är en sparad bild av koden precis som den ser ut just nu.
- Versionshistorik - En lista med alla mina commits som visar vad jag har ändrat och hur projektet har vuxit fram.
